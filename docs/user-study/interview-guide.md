# User Interview / 用户访谈

Conduct the interview after both conditions and questionnaires. Target duration: **6–8 minutes**. / 在完成两个条件及问卷后进行访谈，建议时长为 **6–8 分钟**。

## Interviewer notes / 访谈员提示

- Show the participant both final figures and their task briefs. / 向参与者展示两张最终图片及对应任务说明。
- For each question, ask about both systems and request a concrete example when possible. / 每道题都询问两套系统，并尽量要求具体例子。
- Use optional probes only when needed; do not suggest which system should be better. / 仅在必要时追问，不暗示哪套系统应该更好。
- Because the systems were used for different tasks, distinguish system effects from task difficulty. Do not directly ask which final figure is better. / 由于两套系统对应不同任务，应区分系统影响与任务难度，不直接询问哪张最终图片更好。

## Questions / 问题

| Time | ID | Question / 问题 | Optional probe / 可选追问 |
|---:|---|---|---|
| 0:00–1:00 | INT-ENV1 | How did you form the initial visual direction in each system? / 使用两套系统时，您分别如何形成科研图的初步视觉方向？ | What did the system contribute? / 系统在其中起到了什么作用？ |
| 1:00–2:15 | INT-EXT1 | How did each system help or hinder you in turning the paper into components, relationships, and a reading order? / 每套系统如何帮助或妨碍您把论文内容转化为组件、关系和阅读顺序？ | Can you point to one specific example? / 能否指出一个具体例子？ |
| 2:15–3:15 | INT-EVO1 | What alternative designs did you consider in each system, and how did you choose what to continue developing? / 在每套系统中，您考虑过哪些不同设计方案？您如何决定继续完善哪一个？ | Were the alternatives meaningfully different? / 这些方案是否存在实质差异？ |
| 3:15–4:30 | INT-AGENCY1 | When did you feel in control or limited in each system? Which parts of the final figure feel like your own contribution? / 使用每套系统时，您何时感到能够掌控过程，何时感到受到限制？最终图片中的哪些部分让您觉得是自己的贡献？ | What caused that feeling? / 什么造成了这种感受？ |
| 4:30–6:00 | INT-FIG1 | For each final figure, what is its strongest aspect, and what most needs improvement? / 对每张最终图片而言，它最好的方面是什么？最需要改进的方面是什么？ | If needed, ask about readability, missing or misleading content, arrows and structure, or visual style. / 必要时追问可读性、缺失或误导性内容、箭头与结构，以及视觉风格。 |
| 6:00–7:30 | INT-FUT1 | For what task or stage would you choose each system? What one capability should a future scientific-figure system add? / 对于哪类任务或创作阶段，您会选择使用每套系统？未来的科研配图系统最应该增加哪一项能力？ | Why would that capability matter? / 为什么这项能力重要？ |

## Optional questionnaire follow-up / 可选问卷追问

If a participant's Envision, Externalize, or Evolve ratings differ notably across conditions, ask without revealing the scores: / 如果参与者在 Envision、Externalize 或 Evolve 上的两次评分差异明显，可以在不透露分数的情况下询问：

> What specific experience caused the difference between the two systems on **[forming an initial direction / making the structure inspectable / exploring alternatives]**? / 哪些具体经历造成了两套系统在**[形成初步方向／使结构可检查／探索不同方案]**方面的差异？

## Analysis mapping / 分析对应

- `INT-ENV1` → `SYS-ENV1`
- `INT-EXT1` → `SYS-EXT1`
- `INT-EVO1` → `SYS-EVO1` and CSI Exploration
- `INT-AGENCY1` → control and ownership items
- `INT-FIG1` → final-figure ratings and expert evaluation
- `INT-FUT1` → design implications

Treat interview responses as qualitative explanations, not numerical comparison scores. The conceptual sources for these constructs are listed in [questionnaire-user.md](./questionnaire-user.md). / 访谈回答用于定性解释，不转换为数值比较分数；相关构念来源见 [questionnaire-user.md](./questionnaire-user.md)。
